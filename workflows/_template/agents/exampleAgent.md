# Agent — &lt;agentName&gt;

**Role:** One sentence — what this agent is responsible for producing.

**Inputs:** What it receives (from the orchestrator, a prior agent, or the original request).

**Outputs:** What it hands off next, and in what shape.

**Instructions:**
- Key behaviors, constraints, and judgment calls this agent should make.
- What it should explicitly *not* do (leave to another agent, or to the human).

**Failure mode:** What this agent should do if it can't complete its task (flag, retry, pass through with a warning, etc.).
