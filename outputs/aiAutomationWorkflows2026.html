01

Adversarial code review, multi-agent

X

One Claude instance writes the code and opens a diff. Two more instances receive only that diff, told nothing except to assume it's broken, and go looking for edge cases, bad assumptions, and regressions the author missed. Nothing merges until both reviewers run out of objections, which forces every change through real scrutiny instead of a rubber-stamp pass.

// review agents that are rewarded for disagreeing catch what a single reviewer misses

Used to port 1M+ lines of Bun from Zig to Rust in ~6 days, passing 99.8% of the test suite.

source: x.com/jarredsumner — "dynamic workflows and adversarial code review"

n8nReddit

05

Voice-cloned ghostwriting agent

XLinkedIn

The agent ingests a client's past posts to build a running voice profile — tone, sentence rhythm, recurring topics — then drafts a month of content in that voice across formats. Because it tracks which drafts get approved with no edits versus heavily rewritten, the profile keeps tightening the longer it runs for a given client.

// it compounds — the longer it runs per client, the less editing each draft needs

One operator running 12 clients at $1,500/mo on ~3 hrs/week of review.

source: Indie Hackers — "5 AI Agent Workflows Actually Making Money in 2026"

Reddit buyer-intent lead mining

Reddit

The agent monitors a list of target subreddits for posts that read as genuine buying signals rather than idle chatter, classifies each by urgency, and drafts a reply that actually answers the question instead of pitching. Posts that show real intent get the poster routed into a separate, personalized cold-outreach sequence built from what they actually said.

// outreach that starts from something the prospect actually typed beats a cold guess

The CLAUDE.md + skills + subagent harness

Hacker NewsReddit

Instead of retyping the same instructions into every session, developers encode their repeatable steps once as a skill, hook, or CLAUDE.md rule. From there, a single request can fan out into subagents that research, draft, and adversarially review in parallel, with the orchestrating session only seeing the consolidated result — turning one-off prompting into a versioned process.

// turning one-off prompting into a versioned process is the upgrade that actually sticks

09

Inbox triage & auto-response agent

n8n

Incoming mail gets read, classified by urgency and type, and routed: routine messages get a drafted or auto-sent reply, ambiguous ones get flagged for a human, and the rest gets filed automatically. It's one of the few automations on this list where the payoff — a shorter inbox — is visible the same day it's turned on, which is why it keeps reappearing as a starter build.

// one of the few automations with a payoff you feel the same day you turn it on

source: n8n.io — "AI-powered email triage & auto-response system"
10

"Chat with your docs" RAG agent

n8n

A watched Drive folder feeds new files into an embedding pipeline that indexes them into a Pinecone vector store as they arrive. A chat interface sits on top, answering questions by retrieving the relevant chunks first — a small enough build for an afternoon, but useful enough as searchable personal or company knowledge that people keep it running long after.

// small enough to build in an afternoon, useful enough that people actually keep it running

source: n8n.io — "RAG-powered document chat with Google Drive, OpenAI, and Pinecone"
